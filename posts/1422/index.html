@immersivebama 교수님의 포스팅을 따라해서, CV 파일을 로컬에서 업데이트하면 자동으로 홈페이지가 업데이트 되도록 만들어보았습니다. 우선 CV는 워드로 관리합니다. 저장하는 순간 맥북이 파일 변경을 감지하고, 워드 파일을 파싱해서 JSON 데이터로 바꾸고, 깃허브에 자동으로 커밋,푸시합니다. 이때 웹사이트는 이 JSON을 읽어서 리서치 페이지와 CV 페이지를 업데이트를 합니다. CV 페이지에는 pdf 버젼 CV를 페이지에 풀로 렌더링해서 보여주고, Download CV와 Open in New Tab 버튼도 만들어두었습니다. 이제 저는 워드 파일 열어서 한 줄 고치고 저장하는 것만 하면 되네요. 아주 마음에 듭니다!
